# PWA Store locked screens

Editorial store UI. Product name stays **PWA Store**.

Visual system: canvas `#F4F1EA`, cards white, ink `#141414`, muted `#6B6A66`, teal `#0D7377` for signal only (Curated / installed / offline). Inter + Instrument Serif. Black 52px fill **Install** — never Play-green or iOS-blue. After install: outlined **Open** + teal “On your Home Screen.” No star ratings.
